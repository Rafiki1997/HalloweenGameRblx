## Rebuild, preview, upload, harvest (PowerShell, project directory)

Close Blender before rebuilding `town.blend`. Never rebuild it between an upload and the ID harvest.

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.1\blender.exe' --background --disable-autoexec --python-exit-code 1 --python tools/blender/build_assets.py -- --out assets
& 'C:\Program Files\Blender Foundation\Blender 5.1\blender.exe' --background --disable-autoexec --python-exit-code 1 --python tools/blender/render_previews.py -- --out assets
```

Upload: open `assets/town.blend`, press N over the 3D viewport, open the Roblox tab, log in if asked, choose
your account under Upload to, select the collections named in the table (folder icons in the Outliner, not
the meshes), click Upload, wait for a green checkmark on each, press Ctrl+S, close Blender. Collections that
already carry a `Roblox Package ID` upload as a new version of the same asset.

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.1\blender.exe' --background --disable-autoexec --python-exit-code 1 --python tools/blender/harvest_ids.py
python tools/gen_asset_ids.py
python tools/gen_assets_doc.py
python tools/build_place.py
python tools/build_place.py --test
python tools/verify.py
```

## Runtime notes

- Visible meshes are non-collidable; every asset ships a `Collision` mesh that is invisible and collidable.
- MeshParts are coloured by the role suffix of their name. `Glow` and `Accent` are Neon; `Accent` takes a
  per-instance colour (Haunt hues, blue-white fountain spirit, violet portal and altar).
- Whole-town budgets: 400,000 triangles, 500 MeshParts, 1,500 primitives, 60 lights, 3 shadowed lights.
- A configured asset that fails to load produces a labelled placeholder and one warning per asset.
